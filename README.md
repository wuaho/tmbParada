# TMB Stop Widget

Native Android home-screen widget written in Kotlin and Jetpack Glance. It
shows the next TMB Barcelona bus arrivals for a configured stop.

## Features

- Idle mode does not query the network or maintain a periodic timer.
- `REFRESH` starts a ten-minute live window.
- During the live window, TMB is queried every 30 seconds using one-time
  WorkManager requests.
- The final request clears the active state when the ten-minute window ends.
- The latest arrivals, lines, and update time are stored in `SharedPreferences`
  so the widget remains useful across restarts.
- The UI uses Glance with day/night colors compatible with Material You.

## TMB API

1. Open [TMB Open Data](https://developer.tmb.cat/).
2. Create an account or sign in.
3. Request an application from the credentials area and copy the `app_id` and
   `app_key` values.
4. Add these properties to `local.properties`. Keep any existing `sdk.dir`
   generated by Android Studio:

   ```properties
   TMB_APP_ID=your_app_id
   TMB_APP_KEY=your_app_key
   TMB_STOP_ID=2903
   ```

   `TMB_STOP_ID` is the numeric identifier of the stop to query.
5. Never commit `local.properties`. The credentials are converted to
   `BuildConfig` fields during compilation and are not included in the
   repository.

The application uses this request:

```text
GET https://api.tmb.cat/v1/ibus/stops/{stop_id}?app_id={app_id}&app_key={app_key}
```

## Build and Install

Requirements: recent Android Studio, Android SDK 35, and JDK 17 or later.

```bash
./gradlew assembleDebug
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

Open the application to check the configuration, then add **TMB Stop** from
the home-screen widget picker.

## Refresh Architecture

The refresh callback stores `activeUntilEpochMillis` and enqueues a
`OneTimeWorkRequest`. The worker queries TMB, updates the state, and enqueues
the next request using `APPEND_OR_REPLACE`. When less than one interval remains
before the deadline, it enqueues a short final request and returns the widget
to idle mode. The widget provider sets `updatePeriodMillis` to `0`, so Android
does not start periodic background updates.

## Customization

- Default stop: `TMB_STOP_ID` in `local.properties`.
- Refresh interval: `REFRESH_INTERVAL_SECONDS` in
  `app/src/main/java/com/example/tmbparada/data/TmbConfig.kt`.
- Live window duration: `LIVE_WINDOW_MILLIS` in the same file.
